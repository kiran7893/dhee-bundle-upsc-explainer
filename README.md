# @dhee_ai/bundle-upsc-explainer

Cinematic documentary explainer pipeline for [Dhee](https://github.com/dheeai/dhee-core).

Turn a **topic** or a **complete researched project** into a narrated explainer video:

- LLM outline → scene plan with narration-synced beats
- Krea2 cinematic stills per beat
- OmniVoice design → Higgs voice-clone narrator
- Ken Burns + selective LTX motion
- Timed keyword/timeline/revision graphics (`video.graphics`)
- Optional karaoke captions (`cv.captions`)

## Install

From the Dhee desktop **New Project** screen, search npm for `upsc` and install `@dhee_ai/bundle-upsc-explainer`.

## External runners

`dhee-runner-tts`, `dhee-runner-video-graphics`, `dhee-runner-captions` (auto-installed by the desktop).
